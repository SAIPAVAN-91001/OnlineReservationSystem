# 🚆 Online Reservation System

A simple web-based railway ticket reservation system developed as part of the **Oasis Infobyte Java Development Internship**.

## 📌 Features

- 🔐 User Login
- 🏠 Dashboard
- 🎫 Book Railway Ticket
- 🧾 Generate PNR Number
- 📋 View Ticket Details
- 🖨️ Print Ticket
- ❌ Cancel Ticket
- 🚪 Logout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP
